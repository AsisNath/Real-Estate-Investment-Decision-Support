# Policy topic checklist and query patterns

Always cover all five topics, even when a topic comes back quiet — absence of
regulation is a finding.

## 1. Short-term rental (STR) rules — city/county level
Queries:
- "[city] [state] short-term rental ordinance permit requirements [current year]"
- "[city] STR license fee renewal"
Look for: license/permit requirement, owner-occupancy tiers, fees, license term,
caps or zoning limits, platform enforcement, hotel/occupancy tax, penalties,
processing time, upcoming effective dates.
Official sources: city .gov development-services or code-compliance pages,
municipal code (municode.com/library or city-hosted code).

## 2. Landlord–tenant law — state level
Queries:
- "[state] landlord tenant law security deposit return deadline notice to vacate"
- "[state] property code security deposit"
Look for: deposit return deadline, deposit caps, itemization requirement,
bad-faith penalties, required notice periods, any city just-cause eviction rules.
Official sources: state statute sites (e.g., statutes.capitol.texas.gov,
leginfo.legislature.ca.gov), state law library guides (guides.sll.texas.gov).

## 3. Rent control / rent stabilization — state AND city level
Queries:
- "[state] rent control law preemption"
- "[city] rent stabilization ordinance" (city-level matters: LA's RSO is stricter
  than California's statewide AB 1482 cap)
Look for: statewide cap or statewide ban, city ordinance, which buildings are
covered (construction-date cutoffs), allowed annual increase, vacancy decontrol.

## 4. HOA / deed restrictions — state law + property level
Queries:
- "[state] HOA authority restrict rentals leasing"
- "[HOA name] rental restrictions CC&R" (only if HOA is named)
Look for: whether state law lets HOAs restrict/ban rentals or STRs, amendment
vote thresholds, limits on HOA power over tenants.
**Property-level CC&Rs are almost never findable by search — say so and point
to county records.**

## 5. High-attention synthesis
Not a search — a judgment step. HIGH = could materially change the buy decision
(STR ban/enforcement, rent cap covering this building, HOA rental restriction,
near-term ordinance effective date). INFO = investor-relevant context (e.g.,
statewide rent-control ban). LOW = routine compliance items.

## Source-quality ladder (best → worst)
1. City/state .gov page or hosted statute text
2. State law library / court self-help guides
3. Municipal code hosting (municode, amlegal)
4. Law-firm client alerts (usually accurate, sometimes stale)
5. Property-management / STR-industry blogs (frequently stale or promotional —
   never the sole source for a number)
